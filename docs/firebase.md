# Configuração do Firebase

Este documento descreve o processo de configuração do Firebase no projeto Flutter.

A configuração deve ser realizada antes da implementação das funcionalidades que utilizarão o Firebase.

---

## 1. Pré-requisitos

Antes de iniciar, é necessário ter instalado:

- Flutter
- Dart
- Firebase CLI
- FlutterFire CLI

Também é necessário possuir acesso ao projeto Firebase utilizado pela aplicação.
